CSS Properties Technical Questions - Answers (Toward the end of the sessions questions)


1. Text-Transform Property in CSS
The text-transform property controls the capitalization of text.

Values:

uppercase - converts all text to uppercase

lowercase - converts all text to lowercase

capitalize - capitalizes first letter of each word

none - no transformation (default)

Example:

css
.uppercase { text-transform: uppercase; }
.lowercase { text-transform: lowercase; }
.capitalize { text-transform: capitalize; }
2. Text-Decoration Property in CSS
The text-decoration property adds decoration lines to text and is a shorthand for decoration-line, color, style, and thickness.

Values:

underline - adds line below text

overline - adds line above text

line-through - adds line through text

none - no decoration

Example:

css
h1 { text-decoration: underline; }
h2 { text-decoration: line-through; }
h3 { text-decoration: underline overline; }
3. Text-Color Property in CSS
The color property specifies the color of text.

Color Values:

Color names: red, blue, green

Hex codes: #FF0000, #00FF00

RGB values: rgb(255, 0, 0)

RGBA values: rgba(255, 0, 0, 0.5)

Example:

css
h1 { color: red; }
p { color: #0000FF; }
span { color: rgb(255, 0, 0); }
4. Font-Family Property in CSS
The font-family property specifies a prioritized list of font family names for text display.

Values:

Specific fonts: "Arial", "Times New Roman"

Generic families: serif, sans-serif, monospace

Example:

css
body { font-family: "Arial", sans-serif; }
h1 { font-family: "Times New Roman", serif; }
code { font-family: "Courier New", monospace; }
5. Font-Style Property in CSS
The font-style property sets whether font should be styled with normal, italic, or oblique face.

Values:

normal - normal font style

italic - italic font style

oblique - oblique/slanted font style

Example:

css
p { font-style: normal; }
em { font-style: italic; }
.slanted { font-style: oblique; }
6. Font-Size Property in CSS
The font-size property sets the size of the font.

Values:

Absolute sizes: xx-small, small, medium, large, xx-large

Relative sizes: smaller, larger

Length values: 12px, 1.2em, 80%

Example:

css
h1 { font-size: 24px; }
p { font-size: 1.2em; }
small { font-size: 80%; }



IN-BETWEEN TECHNICAL QUESTIONS:
1. What are the CSS units of measurement?
CSS uses units like:

px (pixels): fixed size

em/rem: relative to font size

%: relative to parent element

vw/vh: relative to viewport width/height

cm, mm, in: print-specific units
These help control size, spacing, and layout.

2. What are the different types of SELECTORS in CSS?
Common types include:

Universal selector (*)

Type selector (div, p, etc.)

Class selector (.className)

ID selector (#idName)

Attribute selector ([type="text"])

Pseudo-classes (:hover, :first-child)

Pseudo-elements (::before, ::after)
